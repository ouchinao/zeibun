## 名前（30 字以内）

zeibun 税法検索

## サブタイトル（30 字以内）

税法の条文を最新で、オフラインでも

## プロモーション用テキスト（170 字以内）

所得税法・法人税法・消費税法・租税特別措置法・地方税法など約 310 の税制法令を、e-Gov 法令検索の公式 API から起動時に最新化。改正の有無と施行予定を一覧で確認できます。

## 説明

本アプリはデジタル庁・e-Gov の公式アプリではありません。法令データは e-Gov 法令検索（https://laws.e-gov.go.jp/）の法令API Version 2 から取得しています。

税務の実務で条文を引くための、税制法令に絞った検索・閲覧アプリです。

- 起動するたびに法令一覧を取り直し、改正があった法令、施行予定のある法令に印を付けます
- 法令名・略称（所法、法法、措法など）・条番号で探せます。「法法22」のように打てば法人税法第二十二条へ直接ジャンプします
- 条・項・号・表・ルビを崩さずに表示し、目次から移動できます。本文内の語句検索、附則の切替、改正履歴の確認ができます
- 一度開いた法令は端末に保存され、オフラインでも読めます
- 「全法令を端末に保存」で約 310 法令をまとめて保存すると、すべての条文を横断して全文検索できます
- 法令と条をブックマークできます

表示内容の正確性・最新性は保証しません。正本は官報および e-Gov 法令検索で確認してください。各法令の画面に取得日時とリビジョンを表示しています。

アカウント登録は不要で、利用状況の収集や広告はありません。通信先は e-Gov 法令検索のみです。
